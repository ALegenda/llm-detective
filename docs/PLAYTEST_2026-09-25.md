# Проверка расследования — 25 сентября 2026

## Условия

Создание сюжетов и игровые действия выполняются только через Chrome средствами Computer Use: видимые элементы, ввод текста, клики, чтение страницы. База, сохранённый blueprint, игровые API, консоль браузера и технические логи сюжета для прохождения не использовались. Проверки кода используют отдельные контролируемые тестовые фикстуры.

## Изменения

- Кнопки предметов отправляют точное действие и идентификатор проверки, без повторного языкового распознавания.
- Карточки содержат доступные проверки и цену во времени. Чтение внешнего вида и сохранённых результатов бесплатно. Повторный поиск всё ещё может обнаружить заново спрятанный предмет.
- Реплики проверяются на смысловую связь с вопросом, допустимые знания, первое лицо и согласованный грамматический род. Неудачная реплика переписывается, а авторские справки не используются как запасной ответ.
- Контекст собеседника включает видимую текущую обстановку и его внешность; недоступные улики туда не добавляются.
- Блокнот сгруппирован по источникам, имеет поиск и фильтры. Записи раскрываются по необходимости. По авторским темам сохраняются дословные выдержки, полные беседы остаются в чатах. Приветствия и пустые отказы не должны становиться уликами.
- Последний результат показан в ходе расследования; предыдущие действия свёрнуты, новые записи связаны с блокнотом.
- Генерация дополнительно сверяет начальное физическое состояние с происшествием, правдой и результатами открытий контейнеров.

## Автоматические проверки

120 тестов проходят (последняя проверка 26 сентября). Проверены прямое выполнение кнопок без AI, идемпотентность, недоступность скрытых/чужих проверок, повторное чтение без расхода времени, повторный поиск спрятанного предмета, дословные выдержки, переписывание неправильной речи и отсутствие изменений мира при неудачной проверке. Проверка синтаксиса JavaScript и проверки CI проходят.
