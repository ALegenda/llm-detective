## Шкала и условия

До генерации зафиксирована [шкала v1](STORY_QUALITY.md): пять аспектов
по 0–2. Контроль проводится через интерфейс, без скрытого плана/БД/консоли.
Оценка за отчёт игрока и качество истории — разные величины.

## Исправления до контрольных историй

Версия `fb6eeec`:

- UI диагностики существующих завершённых дел показал `provider_429` и
  повторные отклонения обычных делений штангенциркуля, слабой выраженности
  эмоций, незначительных деталей рамки/фона. Были и настоящие ошибки:
  читаемые выдуманные даты и неверная идентичность персонажа.
- Убрана предварительная генерация шести эмоций каждого персонажа.
  Эмоции заказываются при фактическом появлении; базовый портрет остаётся.
- Проверка иллюстраций требует конкретный дефект, допускает обычные деления,
  нечитабельные штрихи, спокойные эмоции и несущественные художественные
  различия. Читаемый выдуманный текст, спойлер, другой объект/человек остаются
  основаниями для отклонения. Промпт документов явно отделяет описание
  содержимого от того, что следует рисовать.
- 429: ограниченные повторы через 60–300 секунд, с учётом Retry-After.
  Сбой проверки не заставляет заново рисовать уже сохранённый файл.
- Отчёт: каждый фиксированный критерий получает 0/1/2; сумма нормируется
  до 10, ошибочные утверждения вычитают по 0,5 (не более 2). Интерфейс
  показывает критерии, цитаты игрока, объяснения и размер вычета. Дополнительные
  неподтверждённые замечания не обнуляют правильно доказанное решение.
- Оценка сюжета: отдельная добровольная форма из пяти аспектов с пояснениями,
  лучшим моментом и раздражением. Сохранение заменяет предыдущую оценку
  попытки; без ответа оценка отсутствует. Старым отчётам баллы не выдумываются.
- Длина теперь проверяется по числу материальных источников, а не только
  локаций/людей: 7–9 / 10–12 / 13–16. Сложность управляет глубиной сопоставления.
- Добавлено явное отключение бюджета AI значением 0 для разрешённого окна
  тестирования. На момент публикации настройки сервера не изменялись.

Локально: 139 тестов, проверка синтаксиса обоих JS-модулей и `git diff --check`
пройдены. Реальные новые прохождения и визуальная проверка ещё впереди.

## Диагностическая итерация 1 — не итоговый контроль

`5b81259` развёрнут (Live). Во время подготовки короткого дела в готовом
длинном деле были выполнены чтение блокнота (19:03), протокола (19:05),
разговор с Ириной (19:07) и переход в лабораторию (19:11). Очередь второй
генерации больше не задерживала команды. Ответ Ирины был релевантным,
от первого лица, без выдуманной амнезии.

Длинное дело: **«Пепел вместо ответа»**, case `c19575b75b044440ab4a487ec6eb6e08`,
attempt `9b0874b2936a46428801fd2c7ba6b5b7`. Существенный дефект: уже при первом
входе в лабораторию видны имена «Подменённый образец К-17» и «Бумажная метка
на подменённом образце», хотя вводная требует установить подмену. Карточка
«Фотокарточка сравнительной микроскопии» пока не имеет доступного действия,
кроме свободного ввода. Множество заранее готовых сравнительных документов
ослабляет самостоятельное исследование. Три фрагмента ответа Ирины имеют
одинаковые названия — особенно плохо в списке выбора доказательств.

Полное слепое прохождение остановлено; эту итерацию нельзя считать одним
из двух требуемых успешных контрольных сюжетов. Общая оценка интереса не
выставляется по незавершённому исследованию. Дефекты исключают максимум.

Для проверки оценщика через UI отправлен намеренно неполный отчёт по двум
документам и трём фрагментам разговора, без обвинения конкретного человека
и без утверждения о доказанном способе. Результат **1,7/10**: мотив зачтён
2/2, остальные критерии 0/2, вычет за ошибки 0. Оценщик не превратил слова
«не доказал» в обвинение. Финальная истина просмотрена только после этой
отправки. Она подтверждает связную основу истории, но не устраняет дефект
публичных названий. Также выявлен лишний повтор identity/method/motive в
общих критериях поверх критериев конкретного дела.

Короткое дело `22b40aea0c5f4bbd9b9751ffe13952c7` достигало финальной проверки,
возвращалось на исправление и показало «Подготовка приостановлена». Позже
панель операций ещё показывала running/4; диагностическая причина прочитана
после исключения дела из слепого контроля: доказательства распоряжения
убрать куклу и получения ключа не устанавливают личного физического переноса,
которого требует критерий. Требования к решению не должны включать скрытые
непроверяемые детали только потому, что автор знает их в своей истории.
Эта история также не засчитывается в финальные два прохождения.

## Исправления для следующей итерации

Pipeline v6: публичные названия без авторских ярлыков подмены/подлинности;
несколько проверок одного и того же физического предмета вместо выдумывания
новых экспертных листов; независимость доказательств считается по предметам;
минимум 1/2/3 сравнений или опытов по длительности, для длинного — материальный
опыт. Количество наблюдений/проверок остаётся 7–9/10–12/13–16, физических
источников минимум 5/7/9. Это уточнение структуры мира, шкала интереса v1
не менялась.

Критерии новых дел имеют отдельные аспекты identity/method/motive без
повторного добавления общих критериев. Старые разборы не пересчитываются.
Показания подписываются их содержанием, включая уже сохранённые записи
в интерфейсе; личные секреты в новых финалах подписываются именами.

Все три выбранные старые операции иллюстраций после повторов исчезли из
списка незавершённых/ошибочных, включая фото и полевой лист. Для документов
при упрощении сохраняется описанное открытое/закрытое состояние книги.

Для следующей пары на время тестов WORKERS изменён через Render UI с 2 на 4: отдельные исполнители команд/изображений и два исполнителя генерации. После тестов вернуть WORKERS=2 вместе с бюджетами 200/140/500. Вводные новых дел используют одинаковую нейтральную метку участника, не выделяя авторами скрытого виновного как единственного подозреваемого. Локально 150 тестов пройдены.
