# Контроль качества: 26 сентября 2026

Работа продолжается. Итоговые оценки новых историй пока не выставлены.

## Шкала и условия

До генерации зафиксирована [шкала v1](STORY_QUALITY.md): пять аспектов
по 0–2. Контроль проводится через интерфейс, без скрытого плана/БД/консоли.
Оценка за отчёт игрока и качество истории — разные величины.

## Исправления до контрольных историй

Версия `fb6eeec`:

- UI диагностики существующих завершённых дел показал `provider_429` и
  повторные отклонения обычных делений штангенциркуля, слабой выраженности
  эмоций, незначительных деталей рамки/фона. Были и настоящие ошибки:
  читаемые выдуманные даты и неверная идентичность персонажа.
- Убрана предварительная генерация шести эмоций каждого персонажа.
  Эмоции заказываются при фактическом появлении; базовый портрет остаётся.
- Проверка иллюстраций требует конкретный дефект, допускает обычные деления,
  нечитабельные штрихи, спокойные эмоции и несущественные художественные
  различия. Читаемый выдуманный текст, спойлер, другой объект/человек остаются
  основаниями для отклонения. Промпт документов явно отделяет описание
  содержимого от того, что следует рисовать.
- 429: ограниченные повторы через 60–300 секунд, с учётом Retry-After.
  Сбой проверки не заставляет заново рисовать уже сохранённый файл.
- Отчёт: каждый фиксированный критерий получает 0/1/2; сумма нормируется
  до 10, ошибочные утверждения вычитают по 0,5 (не более 2). Интерфейс
  показывает критерии, цитаты игрока, объяснения и размер вычета. Дополнительные
  неподтверждённые замечания не обнуляют правильно доказанное решение.
- Оценка сюжета: отдельная добровольная форма из пяти аспектов с пояснениями,
  лучшим моментом и раздражением. Сохранение заменяет предыдущую оценку
  попытки; без ответа оценка отсутствует. Старым отчётам баллы не выдумываются.
- Длина теперь проверяется по числу материальных источников, а не только
  локаций/людей: 7–9 / 10–12 / 13–16. Сложность управляет глубиной сопоставления.
- Добавлено явное отключение бюджета AI значением 0 для разрешённого окна
  тестирования. На момент публикации настройки сервера не изменялись.

Локально: 139 тестов, проверка синтаксиса обоих JS-модулей и `git diff --check`
пройдены. Реальные новые прохождения и визуальная проверка ещё впереди.
